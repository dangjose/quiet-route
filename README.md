# Quiet Route

A one-page web app for planning road-bike routes on paved paths, away from main roads and gravel.
Pick a start and destination, then send the route to Komoot or OsmAnd (exact track, as a GPX file) or Google Maps (as stops).

- Routing: [openrouteservice](https://openrouteservice.org) (needs a free key, pasted into the app and saved only on your device)
- Place search: [Photon](https://photon.komoot.io)
- Map: [CyclOSM](https://www.cyclosm.org) / OpenStreetMap

Open `index.html` in a browser, or use the GitHub Pages site.
